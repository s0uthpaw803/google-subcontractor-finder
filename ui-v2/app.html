Keystone Connect — Quick Guide
What it does
Finds local contractor businesses by location and category. Review and download results.
How to Use
  1. Enter location (ZIP, City, State) or use current location
  2. Select Business Query
  3. Set radius
  4. Click Search
  5. Open website/map or download .xlsx
Main Options
  • Use My Location — uses device location
  • Business Query — search common trades or official CSI divisions and sections
  • Preferred Results — shows starred companies
  • API / APIB / GGL — search mode (API = tighter, APIB = broad, GGL = broadest)
  • Prior ON/OFF — hides previously seen results during expansion
  • Get Emails — attempts company email retrieval (slower)
Quick Icons
  • ★ Star / unstar company
  • 🗑 Remove company from query
  • MD emblem — Day / Night mode
  • ? FAQ toggle
Notes
  • Distance shown is straight-line
  • Results are not sponsored ads
  • Results are always ordered nearest to farthest
  • Results depend on listing quality
  • Some listings may lack website or email
