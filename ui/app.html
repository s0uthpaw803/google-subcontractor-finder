Keystone Connect - Quick Guide
What this app does: Finds local contractor businesses by location and category, then lets you review and download results.
How to use
  1. Enter a location (Zip, City, State), or use current location.
  2. Pick a Business Query category.
  3. Set radius in miles.
  4. Click Search.
  5. Open website or map links.
  6. Download .xlsx if needed.
Main options
  • Use my location: uses browser/device location.
  • Business Query: category search or Manual Override.
  • Manual Override: type your own custom search term. Less restrictive.
  • Preferred Results: shows starred companies.
  • Get emails if available: attempts to retrieve relative company email addresses (slower).
Quick Icons
  • Adds/removes a company in Preferred Results.
  • Permanently removes company from this specific query.
  • Day/Night appearance toggle.
  • Pop out / Full size window toggle.
  • API | GGL button: 2 different search modes. Tap the side you want. Active side is red. - API: tighter match. GGL: broader match.
Notes
  • Distance is straight-line (air distance).
  • Results depend on listing data quality.
  • Some listings may not include website/email.
Selecting a parent runs all child categories in that section.
